# Kajiya Build Line

Portable Kajiya development build-line for backlog-governed, handoff-ready, pi.dev-style project work.

This repository is separate from operational products such as kajiya-context-engine.

Core idea:

- project-local backlog is the source of truth
- handoff files make LLM sessions resumable
- builder reasoning is bounded
- QA and validation are deterministic
- git commits preserve evidence
- no project-specific memory is stored globally
